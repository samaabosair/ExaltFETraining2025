# Card Management Interface

A simple front-end card management interface that allows users to create cards and view their saved cards.

## Features

- Create new cards
- View saved cards
- Store card data using browser Local Storage
- Switch between New Card and Your Cards sections
- Simple and user-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage API

## How to Run

Open the `index.html` file in a web browser.
